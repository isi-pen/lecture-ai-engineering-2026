- やったこと：

1回の呼び出しの経過時間と、入力・出力・思考のトークン数を測れるようにapp/ask.pyを改修した。
app/compare.pyを追加。2つのモデルと2つの質問を1回ずつ15秒間隔で順に比較した。
モデルはgemini-3.5-flash-liteとgemini-3.8-flashを使用。
質問は「LoRAとは何ですか？」と「AIE2026の講座の宿題にある「3レベル」とは何ですか？」を選択。
429と503は再送せず、その回の状態として残して次の組み合わせへ進むようにした。
uv run python -m app.compareを実行し、ターミナルに出た比較表を確認した。

全体
unknownの内容を詳細に調べる仕組みも作ってみたい。
第一回 演習講義資料.pdfによると、gemini-3.5-flash-liteが毎分15件・1日500件、gemini-3.8-flashが毎分5件・1日10〜20件前後。
今回のような内容では、毎分の件数上限より、1日上限が制約となる。
上限は件数なので、呼ぶ回数を減らし、1回の応答で多くのトークンを使い、多くの実行時間をかける方が有利。
